Track 2: AI at Application Level

Storage Recommendations That Preserve the Human Decision

SANCHAY identifies recoverable storage candidates, records the proof for each recommendation, and produces a review-only plan. It never deletes or moves a user file.

🛡️

Protected-File Gate

Unique, untracked, uncached files are excluded from the plan before ranking.

⚡

Two-Stage Runway

First-run mtime estimate, followed by measured net growth from later local snapshots.

🎯

Tiered Duplicate Proof

Size -> 64 KB prefix -> full Blake2b, with hardlinks excluded and a named survivor retained.

🇮🇳

Local by Default

Metadata stays local; file bytes are read locally only to confirm duplicate candidates.

Review Priority
Priority = Size × Unchanged Age × (1 − Regret)
Unique files are excluded before ranking
