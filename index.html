Track 1: AI at Application Level

Disk Cleanup That Knows What It Cannot Undo

Every cleanup tool sorts by size alone — treating a 2 GB regenerable build cache and a 2 GB capstone thesis as identical. SANCHAY ranks by recoverability regret, guaranteeing that irreplaceable files are permanently excluded by construction.

🛡️

Zero-Loss Guarantee

Unique single-copy files are mathematically excluded before candidate ranking occurs.

⚡

Single-Scan Runway

Derives daily disk growth directly from inode mtime distribution on run #1 without daemons.

🎯

Tiered Content Hashing

Size collisions -> 64 KB header check -> Full Blake2b only when strictly necessary.

🇮🇳

DPDP Act 2023 Ready

100% local metadata processing. Zero file contents read or transmitted off-device.

Mathematical Objective Function
Priority = Size × Staleness × (1 − Regret)
Regret = 1.00 for Unique Files (Priority = 0.0)
