Track 2 · AI at Application Level

Reclaim space without gambling on files.

SANCHAY ranks only candidates with visible recovery evidence, writes a review-only plan, and keeps the irreversible decision with the operator.

OPERATING BOUNDARY LOCAL SCAN · HUMAN REVIEW · NO DELETION File bytes stay on the machine except when duplicate candidates are compared locally. The browser page below is seeded demo data, not a device scan.

01Protected-file gate

Unique, untracked, uncached files are excluded from the plan before ranking.

02Measured runway

First-run inventory estimate, then a mounted-filesystem used-byte trend from same-root snapshots at least 24 hours apart.

03Duplicate proof

Size -> 64 KB prefix -> full BLAKE2b-256 -> byte comparison, with hardlink aliases excluded from cleanup and allocated-byte totals. Linux reads stay rooted at the selected tree and reject symlink swaps or identity drift.

04Local, policy-bound

Metadata stays local; file bytes are read locally only to confirm duplicate candidates. A separate path-free operator brief supports a secure handoff without transmitting data. On BOSS/Debian, tool-owned stores and system-reserved OS paths stay advisory-only, never raw file-deletion targets.

Review priority model
Priority = Reclaimable Allocation × Unchanged Age × (1 − Regret)

Storage pressure triage

A disk incident is not one number. SANCHAY keeps block availability, file-entry capacity, and inventory disagreement separate.

Seeded mount scenario. These example counters explain the local --capacity-audit; they are not measurements of this browser or server.

20.0 GB free; 1.6 GB is free but unavailable to an unprivileged process. That is a policy boundary, not a deletion recommendation.

02 · FILE-ENTRY CAPACITY 4.2 M entries free

Byte space can remain while the filesystem cannot create another file. The audit surfaces inode/file-entry availability separately.

03 · INVENTORY ACCOUNTING +3.7 GB observed gap

Readable files do not fully explain used blocks. Process-held files, mount layers, snapshots, metadata, and protected paths remain review questions.
